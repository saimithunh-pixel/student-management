
# Student Management System

## Project Description
A mini web application developed using HTML,
CSS, Bootstrap, JavaScript, PHP, and MySQL.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- MySQL
- Git
- GitHub

## Features
- Add student records
- View student records
- Edit student information
- Delete student records
- Database connectivity

## Installation

1. Install XAMPP.
2. Copy the project into htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import database/students.sql.
6. Configure db.php.
7. Open http://localhost/student-management/
